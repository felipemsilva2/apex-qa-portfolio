# Roteamento dos testes

Cada teste do Apex deve ser publicado no repositório de portfólio correspondente:

| Fluxo | Repositório |
| --- | --- |
| Geral e regras de negócio | [apex-qa-general](https://github.com/felipemsilva2/apex-qa-general) |
| Login e autenticação | [apex-qa-login](https://github.com/felipemsilva2/apex-qa-login) |
| Pagamento e checkout | [apex-qa-payment](https://github.com/felipemsilva2/apex-qa-payment) |
| Trial e controle de acesso | [apex-qa-trial-access](https://github.com/felipemsilva2/apex-qa-trial-access) |
| Regressão | [apex-qa-regression](https://github.com/felipemsilva2/apex-qa-regression) |
| Performance em homologação | [apex-qa-performance](https://github.com/felipemsilva2/apex-qa-performance) |

Somente dados sintéticos, mocks e evidências sem informações pessoais devem ser publicados.
